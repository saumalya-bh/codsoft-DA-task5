## 📌 Project Overview
This project is part of the 30-Day Data Analytics Internship at codsoft.in. It delivers an end-to-end data analytics workflow, including Exploratory Data Analysis (EDA), SQL database integration, interactive visual dashboards, predictive modeling, and an automated data cleaning pipeline.
